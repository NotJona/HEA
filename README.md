# Code for The seed-word conundrum: there is no such thing as too much contemporary influence for inferring historical emotion semantics of words

# Abstract
In this contribution we induce historical VAD lexica from static word embeddings and contemporary emotion lexica. 
We extend prior work with additional embedding and induction algorithms, a second contemporary seed lexicon, and 
varying seed lexicon size. Against expectations, larger seed lexica never hurt performance; success depends on 
lexicon size rather than model configuration or specific seed words. Yet our best models still fall short of the 
correlations between contemporary lexica and historical gold data. Tracing this contradiction partly to the gold 
data's own limitations, partly to the limitations of static word embeddings, we argue for a larger, more robust, 
token-based historical VAD resource going forward.
